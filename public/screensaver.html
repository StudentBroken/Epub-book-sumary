Screensaver Converter

Turns pictures into the e-reader's SSI v1 format (300×400 portrait, 2 bits per pixel: white / black / red), splits each into CRC-protected chunks with a parity chunk, and exports a CSV for your Google Sheet. Your tuning is remembered in this browser.

1. Pictures

Drop images here or click to choose (about 30–100 is plenty)

2. Tune the colours (click a thumbnail above to preview it here)

3. Convert & export

Import the CSV once into a tab named Images (File → Import → Upload → Replace current sheet). The sheet never needs updating again: the device picks random images from it every week, preferring ones it does not already have, so even 30 pictures rotate forever.

4. Google Apps Script (copy & paste)

  1. Create the Google Sheet and import the CSV (step 3). Open Extensions → Apps Script, delete the sample code and paste the script above.
  2. Deploy → New deployment → Web app: Execute as Me, access Anyone. Authorise when asked, copy the /exec URL.
  3. Paste that URL below to get the string for the E-Reader Studio (ble.html → WiFi & Colour Screensaver card).
