Screensaver Converter

Turns pictures into the e-reader's SSI v1 format (300×400 portrait, 2 bits per pixel: white / black / red), splits them into CRC-protected chunks with a parity chunk, and exports a CSV to import into your Google Sheet.

1. Pick pictures (download them from Drive first)

Drop images here or click to choose (about 100 is fine)

2. Put it in Google Sheets

  1. Create a Sheet with a tab named Images. File → Import → Upload the CSV, choose Replace current sheet (the header row stays in row 1).
  2. Columns: image_id, chunk_idx, crc32 (decimal), data (base64). One image = 13 rows (header, 10 data chunks, parity, header copy).
  3. Open Extensions → Apps Script, paste tools/screensaver/apps_script.gs from the firmware repo, set SECRET, and Deploy → Web app (execute as you, access: anyone).
  4. In the E-Reader Studio, enter your WiFi and the web app URL followed by ?k=YOUR_SECRET.
